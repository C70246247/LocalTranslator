# LocalTranslator

LocalTranslator is an Android translation and voice-input app. It can translate text using translation models that run locally on the device, helping keep translation processing on-device after a model has been downloaded.

## Features

- Translate text with locally running GGUF models.
- Use Google ML Kit translation as an alternative translation option.
- Translate on-screen text with the floating translator and OCR.
- Enter text by voice using offline Vosk speech recognition.

Models may need to be downloaded before use. Google ML Kit model downloads require an internet connection. Screen capture, microphone, and floating-window features require the corresponding Android permissions.

# LocalTranslator（中文版）

LocalTranslator 是一款 Android 翻译与语音输入应用。它可以使用在设备本地运行的翻译模型处理文本；下载所需模型后，可在设备端进行翻译。

## 功能

- 使用本地运行的 GGUF 模型翻译文本。
- 可选用 Google ML Kit 进行翻译。
- 通过悬浮翻译和 OCR 识别并翻译屏幕文字。
- 使用 Vosk 离线语音识别进行语音输入。

部分模型需要联网下载后才能使用；Google ML Kit 模型下载需要网络。屏幕捕获、麦克风和悬浮窗功能需要授予相应的 Android 权限。
